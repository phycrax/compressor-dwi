# compressor-dwi

Async `no_std` Rust drivers for the Dual Wire Interface (DWI) of variable-speed compressor drives.

| Crate | Compressor | Hardware tested |
| --- | --- | --- |
| [`secop-dwi`](secop-dwi) | Secop NLV/SLVE | Yes, on SLVE18CN |
| [`embraco-dwi`](embraco-dwi) | Embraco CF10B | No |
| [`compressor-dwi`](compressor-dwi) | Shared core used by both | - |

See each crate's README for how to use it.
